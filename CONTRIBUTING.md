# Contributing

Thanks for taking a look. This repo ships under the **Apache License 2.0**.

## Licensing of contributions

Contributions are accepted under the same terms as the project (**inbound = outbound**): by opening a pull
request you agree that your contribution is licensed under Apache-2.0, and you confirm you have the right to
submit it. There is no CLA to sign.

Two rules that matter more here than in most repos:

- **No third-party code or footage.** Detector ideas are fine; copied code is not. The demo clip is generated by
  `examples/make_demo.py` — keep it that way.
- **Standard library first.** Anything new must run with no third-party packages; numpy / OpenCV code goes behind
  a `try: import` guard and degrades to a stdlib result.

## Before you open a PR

```bash
python3 scripts/selftest.py                                  # stdlib path
python3 -m venv .venv && .venv/bin/pip install numpy opencv-python-headless
.venv/bin/python scripts/selftest.py                         # cv2 path
```

Both paths have to pass; CI runs them on Python 3.9 and 3.12. For detector changes, add a fixture that proves
both directions: it fires on the real transition and stays quiet on a pan / handheld / morph clip.

`AGENTS.md` documents the internal contracts if you are driving an agent at this repo.
