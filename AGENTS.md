# AGENTS.md

Instructions for coding agents working **on this repo** (not for agents using the skill — that is `SKILL.md`).

## What this is

A standalone Python tool + agent skill that turns a reference video into a replication template package.
No generation, no network, no API keys. `scripts/desk.py` is the only entry point and prints one JSON per run.

## Layout

| Path | Role |
|---|---|
| `scripts/desk.py` | CLI: `doctor / ingest / speech / recipe / package / status` |
| `scripts/desklib/media.py` | ffprobe/ffmpeg wrappers, frame extraction, raw frame iterator |
| `scripts/desklib/plan.py` | shots → units, speech assignment, `first_frame_time` |
| `scripts/desklib/shots_lite.py` | detector, standard library only |
| `scripts/desklib/shots_cv.py` | detector overlay, needs numpy + cv2 (imported lazily) |
| `scripts/desklib/profile.py` | per-shot brightness / contrast / saturation / warmth / motion |
| `scripts/desklib/recipe.py` | prompt rules, slot normalization, template build |
| `scripts/desklib/handoff.py` | `AGENT.md`, `template.json` handoff block, zip |
| `scripts/desklib/flowhtml.py` | single-file draggable diagram |
| `scripts/selftest.py` | the whole suite: 31 checks, ffmpeg fixtures generated on the fly |
| `references/` | field reference and design notes (also read by the using agent) |

## Before you claim a change works

```bash
python3 scripts/selftest.py                                   # stdlib path
.venv/bin/pip install numpy opencv-python-headless            # optional overlay
.venv/bin/python scripts/selftest.py                          # cv2 path
python3 examples/make_demo.py && python3 scripts/desk.py ingest examples/demo/clip.mp4 /tmp/w1
```

CI runs both paths on Python 3.9 and 3.12. A detector change that only passes on your machine is not done.

## Conventions

- **Standard library first.** Anything new must work with no third-party packages. numpy / cv2 code goes behind
  a `try: import` guard and must degrade to a stdlib result, never to an exception.
- **One JSON object on stdout.** Diagnostics go to stderr. Never print progress to stdout.
- **A failed finder must not fail detection.** Transition finders are wrapped; a bug in one costs its own
  transitions, not the hard cuts. Warn on stderr when you skip something.
- **One boundary per transition.** Events are `(span_start, span_end, boundary_frame, kind, strength)`; the
  ranking is `fade > wipe > dissolve > cut > mg`. Do not add per-frame rules that emit several boundaries for
  one transition.
- **Package paths are relative, folder names ASCII.** The handoff must open on someone else's machine.
- **No third-party footage or code in the repo.** The demo clip is generated by `examples/make_demo.py`.
- **Apache-2.0, inbound = outbound.** Anything you add ships under the same license; add the copyright/notice
  line to `NOTICE` if you bring in a new file that needs attribution.

## Adding a transition finder

1. Write `_my_runs(track) -> list[tuple[int, int, float]]` (start frame, end frame, strength 0–1) in `shots_cv.py`.
2. Register it in the loop in `detect()`: `(finder, "mykind", floor_strength)`.
3. Add the kind to `RANK` if it must outrank a cut.
4. Add a lavfi fixture to `selftest.py` proving both directions: it fires on the real transition, and it stays
   quiet on a pan / handheld / morph clip.
